使い方

  • セルを選んでそのまま入力 → Enter で確定（下へ）、Tab で右へ。Esc で取り消し。
  • ダブルクリック / F2（スマホは同じセルをもう一度タップ）で中身を編集。上の数式バーでも編集できます。
  • = から始めると数式。入力中にセルをクリック／ドラッグすると番地が入ります。例：=B2*C2、=SUM(D2:D10)
  • Shift+矢印・ドラッグで範囲選択。右下の■をドラッグするとコピー（数値2つ以上なら連続データ）。
  • Ctrl+C / X / V でコピー・切り取り・貼り付け（Excel や Google スプレッドシートとの間でも可）。Ctrl+Z / Y で元に戻す・やり直し。
  • 右クリックで行・列の挿入／削除。シート名はダブルクリックで変更、右クリックで削除。
  • 別シートの参照：=Sheet2!A1。$A$1 で絶対参照。
  • データはこのブラウザに自動保存されます。別の端末へ移すときは「CSV保存」を使ってください。

ABS / SQRT / POWER / MOD / PRODUCT / MEDIAN / PI / RAND数学
CONCAT / LEN / LEFT / RIGHT / MID / UPPER / LOWER / TRIM / SUBSTITUTE文字列（& でも連結できます）
