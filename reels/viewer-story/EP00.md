# 第0話 台本（約30秒×2本）

## 主人公アカウント（H）第0話
画面：真っ白な世界。中央に、顔のない人影が横たわっている。

| 秒 | 画面 | セリフ（H の声） |
|---|---|---|
| 0–3 | 人影がゆっくり起き上がる。上に小さく「※この物語はフィクションです」 | 「……ここ、どこだ？」 |
| 3–9 | 見渡す。何もない白 | 「何もない。音もない。……自分の名前も、思い出せない」 |
| 9–15 | 画面の外（視聴者）を見る | 「でも、声が聞こえる。……そこに、誰かいるの？」 |
| 15–21 | 背後の白に、一瞬だけ黒いしみが浮かんで消える（H は気づかない） | 「お願いがある。僕に、名前をつけてくれないか」 |
| 21–27 | 文字：「① 主人公の名前は？ ② ここはどんな場所？」 | 「それと……ここがどこなのかも、君たちが決めて」 |
| 27–30 | 文字：「いいねが一番多いコメントで物語が進みます」 | 「……なんだか、見られてる気がするんだ」 |

## 敵アカウント（X）第0話
画面：真っ黒な世界。光る2つの目だけが見える。

| 秒 | 画面 | セリフ（X の声） |
|---|---|---|
| 0–3 | 目が開く。上に小さく「※この物語はフィクションです」 | 「……目覚めたか」 |
| 3–9 | 黒の中に、白い小窓。中で H が起き上がっている | 「白い世界で、誰かが目を覚ました。名前もない、弱そうなやつだ」 |
| 9–15 | 目が細くなる | 「あいつを消す。それが私の役目……のはずだ」 |
| 15–21 | 目が視聴者の方を向く | 「だが、私にも名前がない。なぜあいつを消すのかも、思い出せん」 |
| 21–27 | 文字：「① 敵の名前は？ ② なぜ主人公を狙う？」 | 「おまえたちが決めろ。私の名と、あいつを狙う理由を」 |
| 27–30 | 文字：「主人公のアカウントはこちら → @（未定）」 | 「……ああ、それと。あいつには言うなよ」 |

## 狙い
- H の背後の黒いしみ（敵の気配）は、H のアカウントだけを見ていても気づける小さなヒント。
- X の最後の「あいつには言うなよ」で、主人公のアカウントに伝えに行く人を誘う。
