# 1分キッチン：レシピデータと表紙の型（form）の書き方

## レシピデータ（recipes/<ジャンル>.json）
配列の1要素が1品。並び順が投稿順。

```json
{"id":"pasta_002_peperoncino",          // <ジャンル>_<3桁の番号>_<ローマ字>。番号は 002 から順に
 "title":"ペペロンチーノ",                 // 料理名（14文字以内が目安）
 "serving":"1人分",                       // 1人分／2人分／作りやすい分量 など
 "ingredients":[["スパゲッティ","100g"],["にんにく","1かけ"]],   // 10個まで。分量は具体的に（g、個、大さじ・小さじ、ml、適量・少々）
 "steps":["湯1Lに塩小さじ2を入れ、…","…"],  // 3〜6手順。1手順は1〜2文、言い切り（〜する）
 "tip":"にんにくは焦がさないよう弱火で。",    // 任意。コツや代わりの材料（1〜2文）
 "tags":["#ペペロンチーノ","#パスタ","#パスタレシピ","#簡単レシピ","#おうちごはん"],  // 5個まで
 "form":{ …表紙の型… }}
```

### 守ること
- 一般的な家庭向けの分量・手順にする。特別な道具や手に入りにくい材料は使わない。
- 安全に関わることは必ず書く：肉・魚・卵は中まで火を通す（鶏肉は特に）。揚げ油は高温に注意。
- 健康効果・ダイエット効果などはうたわない。商品名・店名は使わない。
- 同じジャンルの中で料理を重複させない。
- 分量・時間はおおよその目安。「約」「〜」を使ってよい。

## 表紙の型（form）
`{"vessel":"器", "rim":"#器の色（任意）", "parts":[具, 具, …]}`

### 器（vessel）
| 値 | 見た目 | 向いている料理 |
|---|---|---|
| plate | 白い平皿 | パスタ、主菜、前菜・副菜、ケーキ |
| bowl | お椀（rim で色。漆は #3b2a20） | 汁物、スープ、ぜんざい |
| donburi | 丼 | 丼もの |
| glass | 透明なグラス（中に layer を積む） | パンナコッタ、ゼリー、パフェ、ティラミス |
| cup | 白いカップ | ポタージュ、カップデザート |
| gratin | 楕円のグラタン皿 | ドリア、グラタン |

### 具（parts）の種類 t と主な値
共通：`c` 色、`c2` 2色目（交互に使う）、`n` 数、`s` 大きさ（1が基準）、`r` 散らす半径、`y` 高さの足し、`h` 高さ・厚み
| t | 見た目 | 例 |
|---|---|---|
| nest | 麺のらせん（n 本） | パスタ全般。色でソースを表す（トマト #d9573b、クリーム #f3e2b0 など） |
| mound | ドーム状の山（h でつぶし具合） | ごはん、ポテトサラダ、プリン |
| liquid | 器いっぱいの汁・ソースの面 | 汁物、カレーのルウ、ソース |
| sheet | 薄く広がる層（h 厚み） | 卵とじ、とろけたチーズ、あんかけ |
| omelet | 楕円の卵（オムライスの形） | オムライス、オムレツ |
| layer | グラスの中に下から積む層（h 厚み） | glass と一緒に使う |
| cubes / balls / chunks | 角切り／丸／ゴツゴツした塊を散らす | 豆腐・肉の角切り／白玉・ミートボール／から揚げ・じゃがいも |
| slices | 薄切りを重ねる。shape:"disc" で丸、ring:true で輪に並べる | 豚肉・牛肉／トマト・きゅうり・カルパッチョ |
| sticks | 細い棒を寝かせて散らす | きんぴら、にんじんの千切り、玉ねぎ、ねぎ |
| leaves | 葉っぱ | レタス、バジル、ほうれん草、パセリ |
| specks | 小さな粒 | こしょう、ごま、ねぎ、ハーブ、粉チーズ |
| patty | 平たい楕円（n 個） | ハンバーグ、コロッケ、餃子 |
| fillet | 角の丸い板（n 切れ） | 鮭・魚の切り身、鶏むね肉 |
| cutlet | 切り分けたカツ（n 切れ） | とんかつ、チキンカツ |
| drumstick | 骨付きもも肉（n 本） | ローストチキン |
| log | 横向きの丸太（c2 で断面） | ブッシュドノエル、ロールケーキ |
| cake | 円柱のケーキ（h 高さ） | ショートケーキ、ガトーショコラ |
| triangle | 三角（n 枚重ね） | クレープ、サンドイッチ |
| ring | 輪に並べた葉（リース） | リースサラダ |
| cone | 円すい（ツリー） | ツリー型ポテトサラダ |
| half | 半分ごはん＋半分ルウ（c2 ルウの色） | カレーライス、ハヤシライス |
| swirl | ぐるぐるの飾り | ソフトクリーム、ホイップ |

### 例
```json
{"vessel":"plate","parts":[{"t":"nest","c":"#f1dc9c","n":44},{"t":"specks","c":"#c0392b","n":25,"r":0.6,"h":0.45}]}
{"vessel":"bowl","rim":"#3b2a20","parts":[{"t":"liquid","c":"#b5793a"},{"t":"cubes","c":"#e8a77a","c2":"#f4ecd0","n":9,"r":0.55},{"t":"specks","c":"#4f9a3a","n":40,"r":0.55,"h":0.1}]}
{"vessel":"donburi","parts":[{"t":"mound","c":"#fbf7ee","s":0.95,"h":0.35},{"t":"slices","c":"#8b5a2b","c2":"#a0683a","n":9,"s":0.9,"y":0.2},{"t":"sticks","c":"#f2e3b0","n":10,"r":0.6,"y":0.3}]}
{"vessel":"glass","parts":[{"t":"layer","c":"#fbf6ec","h":0.65},{"t":"layer","c":"#c0392b","h":0.12},{"t":"leaves","c":"#3f8f3a","n":2,"r":0.1,"y":0.8}]}
{"vessel":"plate","parts":[{"t":"ring","c":"#5fa84a","c2":"#3f7a2c","n":34},{"t":"balls","c":"#e74c3c","n":7,"r":0.7}]}
{"vessel":"plate","parts":[{"t":"drumstick","c":"#b5651d","n":2,"s":1.1},{"t":"leaves","c":"#5fa84a","n":10,"r":0.85}]}
```
「その料理らしさ」が一番伝わる具（色・形）を選ぶ。似た料理は、色や具の数で見分けがつくようにする。

## 作り方（tools フォルダで）
```
apt-get install -y fonts-noto-cjk      # 文字のフォント（未導入なら）
npm i three@0.160.0                     # 3D（node_modules は .gitignore 済み）
python3 build.py <ジャンル> ../recipes/<ジャンル>.json ../kitchen-out/<ジャンル>
```
出力：`kitchen-out/<ジャンル>/images/<id>/1.jpg〜4.jpg`（表紙・材料・作り方前半・作り方後半）、`captions.json`、表紙一覧 `review_<ジャンル>.jpg`。
1品あたり数秒。`注意：…はみ出しています` と出たら、その料理の手順を短くする。
