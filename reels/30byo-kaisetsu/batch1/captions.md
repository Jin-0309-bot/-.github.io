```

▼ポイント（19歳以上23歳未満の子どもの場合）

　子どもの所得に応じて63万円〜3万円まで段階的に減ります
```

## #3 生命保険料控除の上限が上がる場合（03_seiho）
```
【30秒解説】23歳未満の子どもなどを扶養している人、保険料控除の上限が上がっています

▼ポイント（令和8年分から）
・23歳未満の扶養親族がいる場合
　新しい契約の一般の生命保険料控除：上限4万円 → 6万円
・介護医療保険料・個人年金保険料は4万円のまま
・3つを合わせた上限は12万円
・一般の生命保険料が年間12万円を超えると、控除は一律6万円

自分の契約と保険料を、確かめてみてください。
```

## #4 ふるさと納税のワンストップ特例（04_furusato）
```
【30秒解説】ふるさと納税、確定申告をしないで控除を受ける方法

▼ポイント
・控除を受けるには、原則として確定申告が必要
・確定申告が不要な会社員などで、寄附先が5団体以内なら
　各自治体に申請する「ワンストップ特例」が使えます
・この場合、所得税からは引かれず、全額が翌年度の住民税から控除

申請の期限は、寄附した自治体の案内で確認してください。
```

## #6 多要素認証ってなに？（06_mfa）
```
【30秒解説】パスワードだけで、アカウントを守れていますか？

▼ポイント
・本人確認の3つの要素
　知識（パスワードなど）／所持（スマホなど）／生体（指紋や顔など）
・このうち2つ以上を組み合わせるのが「多要素認証」
　例：パスワードの後に、スマホに届いた番号を入力
・組み合わせることで、セキュリティを高められます
```

## #7 英語「bored」と「boring」の違い（07_bored）
```
【30秒解説】「I'm boring.」と言うと、意味が変わります

▼ポイント
・I'm bored.＝私は退屈している
・I'm boring.＝私は退屈な人だ
・-ed は気持ちを感じている人、-ing は気持ちを起こさせるものに使う
・interested / interesting、tired / tiring も同じ考え方

今の気持ちを、-ed の形で言ってみてください。
```
