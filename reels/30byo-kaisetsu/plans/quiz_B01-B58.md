# 新シリーズ案「丁寧な英語の言い方 3秒クイズ」B01〜B58（未確認：台本作成時に Cambridge Dictionary で確認する）

形式：「より丁寧なのはどっち？」「この場面で自然なのはどっち？」→ 正解 → 場面の説明 → 言ってみる。
出典候補（grammar/british-grammar/ 以下）：politeness、requests、offers、suggestions、invitations、telephoning、greetings-and-farewells-hello-goodbye-happy-new-year、please-and-thank-you、would-like、could、may、mind、formal-and-informal-language、commands-and-instructions、imperative-clauses-be-quiet など。
